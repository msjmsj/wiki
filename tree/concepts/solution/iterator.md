### 问题

要遍历一个集合,但不想暴露它的内部结构——是数组还是链表,外界不该知道;
而且遍历方式可能不止一种:正序、倒序、跳着来。

### 思路

把「怎么遍历」从集合里抽出来,做成独立的迭代器对象:集合只负责造迭代器,迭代器负责记住走到哪了。
遍历接口统一,内部结构不可见。

### 代码

```python
class NumberSet:
    def __iter__(self):            # 集合只负责造迭代器
        return iter(self._items)   # 内部是数组还是链表,外界不知

for n in NumberSet():              # 遍历接口统一:for 就能用
    print(n)
```

### 为什么有效

遍历和存储分家:集合换实现(数组换链表),遍历代码一行不动;同一集合可同时存在多个遍历进度(多个迭代器互不干扰);
新的遍历方式 = 新的迭代器,集合类不动。

### 代价

简单集合用它略显隆重;迭代中修改集合,迭代器行为要定义清楚(失败即停还是尽力而为),不然就是隐形的雷。

### 与访问者的区别

迭代器是「逐个走一遍」——只给访问通道,不做事;访问者是「走的过程中对不同类型的元素做不同的操作」——做事。
迭代器管遍历,访问者管操作。

### 什么时候用

集合要对外隐藏结构,或需要多种遍历方式。
现代语言(Python、JavaScript)迭代器已是协议级内置,通常不用手写——理解它是为了读懂语言内置的迭代协议。
**反例**——遍历方式永远只有一种且结构公开,直接 for。
